04 — Featured project

auth-platform

A generic, vendor-neutral JWT + passkey authentication platform — the standalone, open-source expression of the auth framework I built at RockWallet. Two independent modules, proven to interoperate over nothing but a public JWKS HTTP contract.

auth-service

A runnable Spring Boot identity provider: registration, password & passkey login, refresh-token rotation, and the JWKS endpoint itself.

auth-jwt-lib

An importable library any Spring service adds to verify RS256 tokens against a standard RFC 7517 JWKS endpoint — no coupling to the issuer.

The security decisions I'm proud of

Not buzzwords — enforced behaviours, each backed by tests in the repo.

🔑

RS256 + JWKS, strictly

Asymmetric signing. The verifier resolves keys by kid from a standard JWKS document and rejects any token whose algorithm isn't exactly RS256 (RFC 8725).

👈

Real WebAuthn passkeys

Touch ID / Windows Hello / security keys via webauthn4j. Single-use challenges and sign-count anti-replay guard against cloned authenticators.

🔄

Refresh rotation, race-safe

Redeeming a refresh token takes a SELECT ... FOR UPDATE row lock, so concurrent redemptions serialise and exactly one can win. Tokens stored only as SHA-256 digests.

🛡

Keys encrypted at rest

RSA private signing keys are AES-256-GCM encrypted with a secret injected at runtime — the app fails closed on startup if it's missing or malformed.

🕳

No enumeration oracles

Login and passkey paths return uniform failures — a caller can't distinguish "wrong password" from "no such user", nor enumerate registered emails.

✅

Proven interop, no mocks

A test boots the real service on a real port, logs in over real HTTP, and verifies the token with the real library fetching the live JWKS — zero mocks in that path.
